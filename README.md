## 线路和延迟：200ms 与 167ms 两个数字分别是怎么来的

先说结论：伦敦这条线是 CN2 GIA 系优化线路，电信和联通回程走 CN2 GIA，移动回程走 CMIN2。写成“三网全程 CN2 GIA”不准确。

去程三网都从北京出口出去，经德国节点直连伦敦机房，电信走 59.43 段 CN2、联通走 AS4837、移动走 CMI 骨干网。回程方面，第三方实测报告记录的返回路由是电信、联通走 CTG/CN2 GIA，移动走 CMIN2。这和法兰克福机房 2025 年 3 月升级后的策略一致（移动回程由 CN2 改为 CMIN2），伦敦是否同步做了同样的调整，公开资料没有明说，但实测结果对得上。

延迟有两套数字。商家和测评文章给的口径是**约 200ms**；另一份带本地测试的测评记录本地 Ping 173ms、全国三网平均 167ms（电信 169、联通 167、移动 163），没有丢包。两个数字不冲突，测试点和时段不同而已，实际落在 165–200ms 这个区间都算正常。

速度方面，测评记录本地下载 7.1MB/s，约合 57Mbps，另一份说最高能到 60Mbps。这里有一条容易被忽略的信息：NodeQuality 的 iPerf3 单线程 TCP 测试显示，回国方向单线程只跑到 100Mbps 左右，也就是说 500Mbps 是端口上限，单线程业务跑不满。如果你打算用它做大文件分发，得考虑多线程或者多连接。

磁盘不是瓶颈。同一份报告里 fio 的 512k 和 1m 块读写都在 520–555MB/s，4k 小文件随机读写约 44MB/s。这个水平和一般 KVM 母鸡上的好盘差不多，别指望整机在单盘速度上能拉开数量级差距。

## 什么情况下该上整机，什么情况下 VPS 就够

¥33000/月 等于一年 39.6 万。伦敦 VPS 入门款一年几百元，最高档月付一千多。两者差两个数量级，所以先确认自己有没有必须整机的需求，再谈性价比。

按需求对号入座：

- **常驻内存超过 16GB**：伦敦 VPS 目前公开的最高档是 4 核 8GB，要跑大型数据库、缓存集群、容器编排，8GB 不够就是不够，这时才轮到 512GB 内存的整机出场。
- **不能忍受邻居影响**：VPS 共享母鸡，CPU 和磁盘 IOPS 会随同宿主机上其他用户波动。做实时交易、直播推流、需要稳定 IOPS 的业务，独享资源是刚需。
- **需要底层权限**：自定义内核、装 Windows、嵌套虚拟化、开全端口、跑必须碰底层网络的软件，VPS 往往受限。
- **需要独立 IP 段或特殊端口**：比如自建邮件服务要用 25 端口，得先问商家是否放行，这一条对 VPS 和整机都适用。
- **只是建站、中转、跑轻量应用、需要英国出口 IP**：VPS 完全够用，¥60/月 的 A1 就能起步，年付档更便宜。

**三、付款只支持支付宝。** 对国内用户方便，对公付款或需要发票的场景要提前确认。
